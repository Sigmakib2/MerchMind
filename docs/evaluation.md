# Retrospective evaluation

The synthetic fixture provides a reproducible engineering baseline, not evidence of commercial performance. It expects a score of 81, coverage 1.00, decision test and a conservative contribution of 331 BDT. Its second lamp has a different power source and variant and must not be accepted as an exact comparable for the first.

For a real merchant retrospective, create an ignored private workspace for each decision-date snapshot. Record the product request, merchant settings, source evidence, supplier terms, local prices and costs that were actually available then. Keep sample outcomes, later orders and later price/FX changes out of the input bundle. Record the original decision timestamp and separate held-out outcome labels.

Run the frozen engine at each decision timestamp through `merchmind.research.run(..., at=decision_time)`. Compare its ranking and recommendations against an agreed historical baseline before looking at outcome labels. Then inspect numeric errors, source support, decision blockers, return allowances, actual landed costs and realized contribution. Publish only aggregate results and redistributable fixture data.

Record cohort size, date ranges, source reachability, unsupported claims, numeric fixture agreement, valid-report/typed-failure rate, latency, human review time and any external agent costs. Audit all quoted prices for provenance. Report missing or inaccessible historical sources rather than replacing them with today's evidence. Do not claim improved commercial performance until a reviewed cohort supports it.
